# Her Şeyi Çay Gibi Demleyen Algoritma

**UYARI: Bu algoritma gerçekten çalışır. Sorumluluk tamamen size aittir. Çay bardağınızı hazırlayın.**

## Nedir Bu?

Bu, insanlık tarihinin en ciddi çay demleme algoritmasıdır. Verdiğiniz herhangi bir kavramı, nesneyi, duyguyu, hatta soyut düşünceyi çay demler gibi demler. 

Patatesle ilgili hiçbir şey yoktur. Yemin ederiz.

## Neden Var?

Çünkü dünya yeterince ciddi değil. Bu algoritma onu daha da ciddi hale getiriyor, abartılı bir şekilde.

## Kurulum

```bash
python demle.py "demlemek istediğiniz şey"
```

Örnekler:
- `python demle.py "trafik"`
- `python demle.py "pazartesi"`
- `python demle.py "GitHub"`

## Özellikler

- Gerçek zamanlı demleme simülasyonu
- Rastgele absürt sonuçlar
- %100 bilimsel (değil)
- Çay içmeyi teşvik eder (veya etmez)

## Katkı

Pull request açın, yeni demleme adımları ekleyin. Ama ciddi olun. Çok ciddi.

## Lisans

Her şey serbest. Demleyin, dağıtın, için.
